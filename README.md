# Jokes Viewer Application

This project is a jokes viewer application built using HTML, Tailwind CSS, and JavaScript.

## Features
- Fetch random jokes from FreeAPI
- Display one joke at a time
- Interactive "Next Joke" button
- Clean and modern UI using Tailwind

## Tech Stack
- HTML
- Tailwind CSS
- JavaScript

## API
https://api.freeapi.app/api/v1/public/randomjokes
